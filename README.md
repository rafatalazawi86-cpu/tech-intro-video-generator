## 🚀 البدء السريع

### المتطلبات
```bash
Python 3.7+
OpenCV
Pillow (PIL)
NumPy
```

### التثبيت

1. **استنساخ المستودع أو تحميل الملفات**
```bash
git clone <repository-url>
cd tech-intro-video-generator
```

2. **تثبيت المكتبات**
```bash
pip install -r requirements.txt
```

3. **إنشاء مجلدات المشروع**
```bash
mkdir -p assets output
```

### الاستخدام

#### الخطوة 1️⃣: ضع صورتك
```
ضع صورتك في: assets/profile_pic.jpg

📋 متطلبات الصورة:
- تنسيق: JPG, PNG
- الحجم المثالي: 400×400 بكسل أو أكبر
- الجودة: عالية ومضاءة جيداً
- الخلفية: بسيطة وواضحة
```

#### الخطوة 2️⃣: شغّل البرنامج
```bash
python rafat_intro_generator.py
```

#### الخطوة 3️⃣: انتظر الفيديو
```
✅ سيتم إنشاء الفيديو في: output/rafat_intro_video.mp4
⏱️ المدة: 8 ثوانٍ
📊 الحجم: حوالي 20-30 ميجابايت
```

## ⚙️ التخصيص والتعديل

### تغيير الألوان

عدّل القاموس `colors` في الملف:
```python
self.colors = {
    'circle_1': (255, 100, 150),   # BGR format
    'circle_2': (100, 200, 255),
    # ...
}
```

### تغيير الاسم والعنوان

```python
self.name = "اسمك هنا"
self.subtitle = "عنوانك هنا"
```

### تغيير المدة

```python
self.duration = 10  # بدلاً من 8 ثوان
```

### تغيير الدقة

```python
self.width = 1280   # بدلاً من 1920
self.height = 720   # بدلاً من 1080
```

### إضافة/تعديل منصات التواصل

```python
self.social_media = [
    {'name': 'Instagram', 'icon': 'I', 'color': (100, 200, 255)},
    {'name': 'منصتك', 'icon': 'M', 'color': (200, 100, 100)},
    # ...
]
```

## 🎨 تأثيرات متقدمة

### الخلفية المتدرجة
تتحرك الخلفية بألوان ناعمة تتغير مع الزمن

### حركات الدوائر
- **الدوران:** تدور الدوائر الملونة حول صورتك
- **النبض:** تتسع وتنكمش بشكل متكرر
- **التوهج:** حدود براقة تحيط بكل دائرة

### حركات النص
- **التلاشي:** ظهور سلس للاسم والعنوان
- **التموضع:** ظهور في الوقت المناسب

### حركات الأيقونات
- **القفز:** أيقونات التواصل تقفز بشكل جميل
- **التزامن:** كل أيقونة لها وقت مختلف

## 🔧 استكشاف الأخطاء

### ❌ المشكلة: لم يتم تحميل الصورة
**الحل:** تأكد من:
- وجود الملف في `assets/profile_pic.jpg`
- أن الملف صورة صحيحة (jpg, png)
- أن لديك صلاحيات القراءة

### ❌ المشكلة: الفيديو بطيء جداً
**الحل:** قلل الجودة أو المدة:
```python
self.fps = 30  # بدلاً من 60
self.duration = 5  # بدلاً من 8
```

### ❌ المشكلة: خطأ في المكتبات
**الحل:** أعد التثبيت:
```bash
pip install --upgrade opencv-python Pillow numpy
```

### ❌ المشكلة: الألوان غريبة
**الحل:** OpenCV يستخدم BGR بدلاً من RGB. قم بعكس القيم!

## 💡 نصائح للحصول على أفضل النتائج

1. **استخدم صورة عالية الجودة**
   - الصورة الواضحة تعطي نتائج أفضل
   - تأكد من الإضاءة الجيدة

2. **خلفية بسيطة**
   - تجنب الخلفيات المعقدة
   - اختر خلفية محايدة

3. **الوجه مرئي بوضوح**
   - لا تستخدم نظارات شمسية
   - تأكد أن وجهك واضح

4. **جرب النسخة المتقدمة**
   - استخدم `advanced_main.py` لتأثيرات إضافية

5. **أضف موسيقى خلفية**
   - استخدم أداة دمج الفيديو مثل FFmpeg
   - اختر موسيقى تناسب المحتوى التقني
